Nesta página temos uso de "ID" e "class" que possibilitam estilizar partes específicas do código.

O uso consiste em determinar uma tag com id em HTML e identificar a mesma tag em CSS com uma "#". Isso faz com que todas as estilizações feitas na CSS sejam aplicadas SOMENTE nessa tag específica e o resto do código fique sem tal formatação.

Para classes a lógica de uso é a mesma: Estilizar um trecho específico. As diferenças estáo na identificação que para classes ocorrem por "." (Ponto) ao invés de "#", na limitação de uso que no caso das classes não há e no principal: Quando determinamos uma classe para uma tag, é possível formatar todas os usos dessa tag com o mesmo estilo, ou seja, ao determinar uma classe para um subtitulo (h2), é possível usar diversos outros h2 com o mesmo estilo, basta identificar todos eles como pertencentes a mesma classe (Algo que não é permitido nos ID's)

O uso de somente um ID por documento é uma regra normativa, o código ainda funcionaria se ussase mais de um, porém não é uma prática recomendada em desenvolvimento Web profissional.
